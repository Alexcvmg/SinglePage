# ⚡ Single Page

**Uma experiência web completa concentrada em uma única página.**

Projeto desenvolvido com HTML, CSS e JavaScript puro para explorar o conceito de Single Page e a construção de uma experiência contínua de navegação.

## ✨ Sobre o projeto

A proposta foi organizar diferentes conteúdos e elementos visuais em uma única página, criando uma experiência de navegação fluida sem depender de frameworks.

O projeto também utiliza imagens, logos e vídeo para complementar a apresentação visual da página.

## 🚀 Funcionalidades

* 📄 Estrutura Single Page
* 🧭 Navegação entre seções
* 🖼️ Utilização de imagens e elementos gráficos
* 🎬 Conteúdo em vídeo
* ⚡ Interações utilizando JavaScript
* 📱 Estrutura responsiva

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
